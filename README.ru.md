# VoxTypeMac

[English](README.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Українська](README.uk.md)

VoxTypeMac — приложение для диктовки в строке меню macOS на Apple Silicon. Нажмите назначенное сочетание клавиш, произнесите текст и нажмите его ещё раз: расшифровка появится в поле ввода, которое было активно в начале записи.

## Требования

- macOS 27 или новее на Mac с Apple Silicon
- Xcode 27
- shellcheck для полной проверки исходного кода
- Необязательно: uv и закреплённые зависимости Qwen3-ASR для локальной модели улучшения распознавания

Приложение использует Apple Speech, AppKit, SwiftUI, AVFoundation и API универсального доступа. Оно не требует учётной записи, не собирает аналитику, не отправляет речь в облачный сервис распознавания и не зависит от личных данных в дереве исходного кода.

## Данные и конфиденциальность

Записи, расшифровки, настройки, загруженные модели, кэши и временные файлы хранятся в ~/Library/Application Support/VoxTypeMac/. В дереве исходного кода и архивах релизов этого каталога нет. macOS может загружать речевые ресурсы в собственное системное хранилище. TCC, элементы входа и системные журналы также находятся под управлением macOS.

Для диктовки VoxTypeMac запрашивает доступ к микрофону и распознаванию речи, к мониторингу ввода для глобального сочетания клавиш и к универсальному доступу для проверки вставки текста. Если подтвердить вставку не удаётся, расшифровка остаётся в буфере обмена.

## Сборка и проверка

    ./verify-source.sh
    ./build-app.sh
    open "runtime/build/VoxTypeMac.app"

Результаты сборки остаются в игнорируемом каталоге runtime/. Разработческие сборки подписаны ad hoc, поэтому после повторной сборки macOS может снова запросить разрешения. Подготовка к стабильному распространению, включая постоянную идентичность подписи и нотариальное заверение, не входит в эту локальную версию.

Чтобы установить собранное приложение локально:

    ./install.sh

Скрипт заменяет только ~/Applications/VoxTypeMac.app. Другие установленные копии приложения и их данные он не затрагивает.

## Необязательное улучшение распознавания Qwen3-ASR

    ./script/install-qwen.sh

Скрипт устанавливает закреплённую версию среды Python и модель в каталог поддержки приложений VoxTypeMac. Сеть нужна только во время установки; распознавание выполняется локально. Версии и лицензии сторонних компонентов указаны в THIRD_PARTY_NOTICES.md, config/qwen-asr.json и файле зависимостей Python с контрольными суммами.

## Структура исходного кода

- Sources/VoxType/: приложение, меню, запись, распознавание, отправка текста и хранение данных
- Tests/VoxTypeTests/: функциональные проверки macOS-приложения и границ работы с данными
- Resources/: метаданные приложения, entitlements и графические ресурсы
- config/: идентичность продукта и закреплённые необязательные зависимости модели
- script/: сборка, упаковка, установка модели и вспомогательные сценарии локального запуска

Исходный код распространяется по лицензии MIT. Для необязательных моделей и сред выполнения действуют собственные условия их поставщиков.
