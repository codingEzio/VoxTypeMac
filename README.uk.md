# VoxTypeMac

[English](README.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Українська](README.uk.md)

VoxTypeMac — локальна програма диктування для панелі меню macOS на Apple Silicon.
Натисніть вибране сполучення клавіш, промовте текст і натисніть його ще раз —
розшифровка з’явиться в полі введення, яке було активним на початку запису.

## Вимоги

- macOS 27 або новіша версія на Apple Silicon
- Xcode 27
- `shellcheck` для повної перевірки вихідного коду
- Необов’язково: `uv` і зафіксовані залежності Qwen3-ASR для локальної моделі уточнення

Програма використовує Apple Speech, AppKit, SwiftUI, AVFoundation та API
«Доступності». У ній немає облікових записів, аналітики чи хмарного сервісу
розпізнавання мовлення, і дерево вихідного коду не залежить від приватних даних
користувача.

## Дані та приватність

Записи, розшифровки, параметри, завантажені моделі, кеші й тимчасові файли
зберігаються в `~/Library/Application Support/VoxTypeMac/`. Ця тека не входить
до дерева вихідного коду чи архівів випуску. macOS може завантажувати мовні
ресурси до сховища, яким керує система. TCC, об’єкти входу та системні журнали
також контролює macOS.

Для диктування VoxTypeMac запитує доступ до «Мікрофона» й «Розпізнавання
мовлення», до «Контролю входу» для глобального сполучення клавіш, а також до
«Доступності», щоб перевірити вставлення тексту. Якщо вставлення не вдається
підтвердити, розшифровка залишається в буфері обміну.

## Збирання та перевірка

```sh
./verify-source.sh
./build-app.sh
open "runtime/build/VoxTypeMac.app"
```

Результати збирання зберігаються в ігнорованій теці `runtime/`. Локальні збірки
підписуються сталою ідентичністю `Alex Local Code Signing`, тому дозволи
приватності macOS зберігаються після повторного збирання. Перед першим
збиранням виконайте `./ensure-signing-identity.sh`. Програму не нотаризовано;
учасники можуть замінити `SIGNING_IDENTITY` власним сталим сертифікатом підпису.

Щоб установити зібрану програму локально:

```sh
./install.sh
```

Це замінить лише `~/Applications/VoxTypeMac.app`. Окрема приватна копія програми
та її дані не змінюються.

## Необов’язкове уточнення за допомогою Qwen3-ASR

```sh
./script/install-qwen.sh
```

Скрипт установлює зафіксоване середовище Python і модель у
`~/Library/Application Support/VoxTypeMac/`. Підключення до мережі потрібне лише
під час установлення; уточнення виконується локально. Версії сторонніх
компонентів і їхні ліцензії наведено в
`THIRD_PARTY_NOTICES.md`, `config/qwen-asr.json` і файлі вимог Python із
зафіксованими хешами.

## Структура вихідного коду

- `Sources/VoxType/`: програма, меню, запис, розпізнавання, передавання та зберігання
- `Tests/VoxTypeTests/`: функціональні перевірки macOS та меж роботи з даними
- `Resources/`: метадані програми, entitlements і графічні матеріали продукту
- `config/`: ідентичність продукту та зафіксовані залежності необов’язкової моделі
- `script/`: допоміжні скрипти збирання, пакування, установлення моделі та локального запуску

Вихідний код доступний за ліцензією MIT. Для необов’язкових моделей і середовищ
використовуйте умови їхніх першоджерел.
